# school-incidents-project
The aim of this project is to answer the following question: Where are the safest schools in NSW?

Data source: https://data.gov.au/data/dataset/nsw-nsw-education-incident-reports-nsw-government-schools

1. Obtain dataset from data.gov.au. Each csv/excel file is separated by year, with different format from 2019 onwards.
2. Clean each file separately and combine into one.
3. Analyse the combined dataset.
4. Data visualisation and report.
